# 📖 Manual del Usuario Final: Sistema CompraVenta

Bienvenido al sistema de gestión de **CompraVenta**. Esta guía te ayudará a dominar las herramientas principales para la gestión de empeños, inventario y ventas.

## 1. 🔐 Acceso al Sistema
Para ingresar al sistema, utiliza tus credenciales proporcionadas por el administrador.
- **Login:** Ingresa tu correo electrónico y contraseña.
- **Sesión:** El sistema mantendrá tu sesión activa. Si el sistema te redirige al login, es porque tu sesión ha expirado por seguridad.

## 2. 🚀 El Flujo de "Empeño Ágil" (Paso a Paso)
Esta es la función más potente del sistema para registrar un empeño rápidamente sin navegar por múltiples menús.

**Paso 1: El Cliente**
- Busca al cliente por su cédula o nombre.
- Si el cliente no existe, haz clic en **"Nuevo Cliente"** y completa los datos básicos.

**Paso 2: El Artículo**
- Describe el objeto: nombre, categoría (Tecnología, Electrodomésticos, Otros) y estado (Excelente, Bueno, Regular, Malo).
- Asigna el precio de compra y el precio sugerido de venta.

**Paso 3: El Contrato**
- Define el monto que le prestarás al cliente.
- Establece el número de cuotas y la fecha de retorno. El sistema calculará automáticamente la fecha de vencimiento.

**Paso 4: Confirmación**
- Revisa el resumen final.
- Haz clic en **"Confirmar Empeño"**. ¡Listo! El contrato ha sido creado y el artículo ha ingresado al inventario.

## 3. 📦 Gestión de Inventario y Ventas
- **Listado de Artículos:** Puedes filtrar artículos por categoría o ver solo los que tienen stock disponible.
- **Realizar una Venta:** Selecciona el artículo, el cliente y el precio final. El sistema reducirá automáticamente el stock.
- **Registrar una Compra:** Cuando compres un artículo a un proveedor, regístralo en el módulo de compras para que ingrese inmediatamente al inventario.

## 4. 💰 Gestión de Pagos
Para mantener un empeño activo, el cliente debe realizar pagos:
1. Ve al módulo de **Empeños**.
2. Selecciona el contrato activo.
3. Haz clic en **"Registrar Pago"**, ingresa el monto y la fecha.
